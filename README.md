# ICU - Ian Cero’s Utils

<!-- badges: start -->

<!-- badges: end -->

The goal of **ICU** is to serve as a catch all package for frequently
used utility functions that generally don’t have a home in other
packages or which are convenient to re-export all in one place.

## Installation

You can install the development version of **ICU** from with:

``` r
# install.packages("pak")
pak::pak("iancero/icu")
```
